## Boolean TypeCasting
Examples:
- bool(100)    # True
- bool(-5)     # True
- bool(0.1)    # True
- bool(0)      # False

**Python treats these values as False:**

- 0
- 0.0
- 0j
- None
- Empty strings ""
- Empty lists []
- Empty tuples ()
- Empty dictionaries {}
- Empty sets set()
