## VARIABLES 

- Variable is a **storage Unit** which stores data or also called assigning the values.
- So, Data can be any type like number, string, decimals ect.
- Ex: a=25
    - a is storage unit that stores the value 25.
- Variables can be modified as you change the value(Variable can reassigned).
- You can assign values to multiple variables in one line Or assign the same value to multiple variables.
- But you can't assign single variable to multiple variables.
    - Ex:You can put 2 or more apples in single bag
         but you can't store single apple in 2 bags.
- 
**Rules for Naming the Variables**
- Must start with a letter (a-z, A-Z) or underscore (_).
    - sailu or Sailu or _sailu
- Can contain letters, numbers, and underscores.
    - ✅Sailu123
    - ✅Sailu_123 
- But con't start with numbers and special characters.
   - ❌ 123sailu
   - ❌ @sailu
   - ❌ $sailu
   - ❌ %sailu
   - ❌ &sailu
- Space should not be used when variables are created and it can't be used by in between words also.
   - ❌ python practice
- Variables can't start with keywords.
   - ❌ range
   - ❌ if
   - ❌ int
- Variables are case sensitive.
